\# Snake Game



Trò chơi Snake được viết bằng Python và Pygame.



\## Tính năng

\- Điều khiển rắn bằng phím mũi tên

\- Hiệu ứng âm thanh và hình ảnh tự thiết kế





\## Yêu cầu

\- Python 3.13

\- Pygame



\## Cài đặt và chạy

```bash

git clone https://github.com/catherine0112/snake-game.git

cd snake-game

pip install pygame

python snake.py

```
